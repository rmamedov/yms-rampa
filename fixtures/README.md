# Фікстури довідника філій

## Файли

- `silpo-branches.json` — повний довідник філій, вивантажений з MCP Сільпо (`silpo_list_branches`): 455 записів, поля `branchId`, `companyId`, `externalId`, `city`, `address`, `latitude`, `longitude`, `hasPickup`, `open`.
- `cities.json` — похідний список міст із кількістю філій: 83 записи.

## Що показав аналіз даних

Довідник придатний як джерело, але містить записи, непридатні для роботи YMS. Сідер `store-service` має їх відфільтровувати, інакше в навігацію водія потраплять неіснуючі точки.

| Спостереження | Кількість | Наслідок для YMS |
|---|---|---|
| Філій усього | 455 | — |
| Унікальних міст | 83 (з них один порожній ключ) | Порожнє місто ламає екран вибору міста в `supplier-web` |
| `open = true` | 435 (20 — `false`) | Закриті філії не активуються |
| `hasPickup = true` | 311 (`false` — 13, **`null` — 131**) | `null` треба нормалізувати до `false`, інакше фільтр поводиться непередбачувано |
| Порожнє `city` | 8 записів (7 із них і без `address`) | Непридатні для бронювання |
| `externalId` з префіксом `delete_` | 5 записів | Видалені філії, які лишилися у вибірці |
| Координати `null` | 1 запис (`externalId 2505`) | Кнопка «Побудувати маршрут» не працює |
| Координати поза межами України | 3 записи: `3656` (50.1, 49.2), `567898` (1.0, 1.0), `791091` — Нью-Йорк, вул. Волл Стріт | Явно тестові філії |

## Правила фільтрації для сідера

Запис не імпортується як придатний до активації, якщо виконується хоча б одна умова:

1. `externalId` починається з `delete_`;
2. `city` або `address` порожні;
3. `latitude` або `longitude` порожні;
4. координати поза межами України (bbox: `lat 44.0–52.5`, `lon 22.0–40.5`).

Такі записи все одно зберігаються в довіднику зі статусом `ymsStatus = not_configured` і позначкою причини — щоб їх було видно в адмін-панелі, але вони не потрапляли до постачальників. Це узгоджується з вимогою SRS: нова філія невидима постачальникам, доки її не налаштують і не активують.

Поле `hasPickup = null` нормалізується до `false`.

## Оновлення фікстури

Файл — знімок для розробки і тестів. У проді джерелом є MCP Сільпо з нічною синхронізацією (розділ 11 SRS): зіставлення за `branchId`, зникнення філії з вибірки веде до `archived` лише після 3 послідовних синхронізацій.
